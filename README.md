# jtthungan — releases

Kho chứa bản cài đặt Windows (.exe) đã build của app jtthungan POS, dùng làm nguồn cho tính năng tự động cập nhật (electron-updater).

**Repo này không chứa source code** — code nằm ở repo private riêng. Các file ở đây được đẩy lên tự động từ GitHub Actions mỗi khi có bản build mới.
